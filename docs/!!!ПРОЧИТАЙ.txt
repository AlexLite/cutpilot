AUTOLOGO — обработка видео через имя файла
===========================================

КАК ПОЛЬЗОВАТЬСЯ
----------------

1. Скопируйте видео в папку autologo.
2. После окончания копирования не открывайте, не перемещайте и не удаляйте этот файл.
3. Через 10 секунд сервис начнёт обработку. Дождитесь появления нового файла:
   - с суффиксом _logo — ролик с логотипом;
   - с суффиксом _nologo — ролик без логотипа.
4. Исходник удаляется только после успешной проверки готового результата.

Важно: не запускайте ролик из сетевой папки, пока не появился результат. Открытый на компьютере
файл блокирует обработку, чтобы не получился битый ролик.

ЧТО ПРОИСХОДИТ БЕЗ КОМАНД
-------------------------

Сервис накладывает логотип: обычный на горизонтальное видео и вертикальный на вертикальное.
Разрешение и частота кадров сохраняются. Видео кодируется на NVIDIA в высококачественном режиме
с целевым средним битрейтом исходника; аудио копируется без перекодирования. В очень сложных
сценах видеобитрейт может кратковременно быть немного выше исходного — это нужно для сохранения
видимого качества.

Если в конце есть тишина тише -20 dB длительностью более двух секунд, она сокращается до одной
секунды. Звук -16 dB не считается тишиной и не обрезается.

КОМАНДЫ В ИМЕНИ ФАЙЛА
---------------------

Добавьте команды в конец имени, перед расширением файла:

    Название ролика [cmd -mp4 -1080p -25fps].mov

Пробелы внутри блока необязательны. Работает и так:

    Название ролика [cmd-mp4-1080p-25fps].mov

Квадратные скобки и слово cmd нужны. Команды пишите латинскими буквами.

    -mp4       Сделать MP4 с H.264 High@L5.1.
    -mov       Сделать MOV. Кодек остаётся H.264, если не указано -hevc.
    -hevc      Использовать H.265/HEVC Main@L5.1. Контейнер по умолчанию MP4.

    -1080p     Сделать высоту ролика 1080 пикселей.
    -720p      Сделать высоту ролика 720 пикселей.
    -480p      Сделать высоту ролика 480 пикселей.
    -360p      Сделать высоту ролика 360 пикселей.

    -25fps     Сделать 25 кадров в секунду. Вместо 25 можно поставить число от 1 до 60.

    -1gb       Постараться уложить итоговый файл в 1 ГБ.
    -100mb     Постараться уложить итоговый файл в 100 МБ.
              Вместо чисел можно подставлять свои значения: -700mb или -2gb.
              При ограничении размера качество и битрейт подбираются под указанный объём.

    -nl        Не накладывать логотип. То же: -nologo.
    -nc        Не обрезать тихий хвост. То же: -nocut.

ПРИМЕРЫ
--------

    Интервью [cmd -mp4 -1080p].mov
    Получится: Интервью_logo.mp4

    Архив [cmd-hevc-720p-25fps-700mb].mts
    Получится: Архив_logo.mp4

    Версия без заставки [cmd -mp4 -nl].mov
    Получится: Версия без заставки_nologo.mp4

    Материал [cmd -mov -nc].mp4
    Получится: Материал_logo.mov

ОБРЕЗКА И СКЛЕЙКА
-----------------

Время записывается через точку, справа налево:

    4.15       = 4 минуты 15 секунд
    01.23.23   = 1 час 23 минуты 23 секунды

    -crp-4.15-4.36
              Вырезать участок с 04:15 по 04:36, остальное оставить.

    -crp=4.15-4.36
              Оставить только участок с 04:15 по 04:36.

    -crp+4.55-5.16+5.26-6.10
              Оставить эти участки и склеить их в указанном порядке.

Удалить несколько участков можно через +:

    [cmd -crp-1.10-1.25+3.40-3.55]

Монтажные команды можно объединять с другими:

    [cmd -crp-4.15-4.36 -mp4 -1080p]

Вырезанные участки точны по времени. При обрезке звук в оставшихся участках кодируется заново,
чтобы он не рассинхронизировался с видео. При любой команде -crp автоматическая обрезка тихого
хвоста отключается: итог определяется только указанными вами таймкодами.
команда -nc её отключает.

------------------

Если не знаете, как назвать файл, скопируйте текст ниже в любой GPT-чат:

    Ты — помощник для самописного сервиса AutoLogo. Сервис получает видеофайл из сетевой
    папки и читает команды в квадратных скобках перед расширением: [cmd команды].
    Сначала спроси исходное имя файла с расширением и что пользователь хочет сделать.
    Если данных не хватает, задай короткий уточняющий вопрос.
    После этого верни ТОЛЬКО одно готовое имя файла, без пояснений и без кавычек.

    Формат: Название [cmd команды].расширение
    Команды можно сочетать и разделять пробелами.

    -mp4 — контейнер MP4, видео H.264 High@L5.1.
    -mov — контейнер MOV.
    -hevc — видео H.265/HEVC Main@L5.1; если контейнер не задан, будет MP4.
    -1080p, -720p, -480p, -360p — высота видео в пикселях.
    -Nfps — частота кадров; N от 1 до 60, например -25fps.
    -Ngb или -Nmb — приблизительный лимит размера, например -1gb или -700mb.
    -nl или -nologo — не накладывать логотип.
    -nc или -nocut — не обрезать тихий хвост в конце.

    Монтаж:
    -crp-НАЧАЛО-КОНЕЦ — удалить этот участок, остальное оставить.
    -crp=НАЧАЛО-КОНЕЦ — оставить только этот участок.
    -crp+НАЧАЛО-КОНЕЦ+НАЧАЛО-КОНЕЦ — оставить несколько участков и склеить по порядку.
    Пример: -crp-1.10-1.25+3.40-3.55 удаляет два участка.

    Таймкод записывается через точку справа налево: 4.15 = 4 минуты 15 секунд;
    01.23.23 = 1 час 23 минуты 23 секунды. Не используй двоеточия.
    Пример результата: Интервью [cmd -crp-4.15-4.36 -mp4 -1080p].mov

ХРАНЕНИЕ И ОШИБКИ
-----------------

Готовые файлы с суффиксами _logo и _nologo автоматически удаляются через 24 часа.
Исходные файлы, этот документ и .error.txt автоматически не удаляются.

Если обработка не началась или завершилась ошибкой, рядом с исходником появится файл .error.txt.
Не удаляйте исходник: закройте его на компьютере, дождитесь окончания копирования и передайте
текст ошибки администратору.
